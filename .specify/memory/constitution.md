# Project Constitution

This file defines the foundational principles, architecture, and constraints for the Frontend (Flutter) application.

## Core Directives
1. **Strict Adherence to Existing Documentation**: 
   Before generating any specifications, plans, or code, you MUST read and follow all markdown files located in the `lib/docs/` directory.
   These files contain the ultimate source of truth for the API design, architecture, database models, AI instructions, git workflow, and feature definitions.
2. **Do Not Hallucinate Architecture**:
   If a feature or pattern is already defined in `lib/docs/`, you must use it. Do not invent new structures if one already exists.
3. **Spec-Driven Process**:
   Use this constitution as the absolute baseline for all `/speckit.specify`, `/speckit.plan`, and `/speckit.implement` actions.
